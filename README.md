A Python program that draws a one-picture summary of the world's news of Thursday 19 November 2026 as a 1024x1024 infographic: the first Trump-Xi-Putin three-way summit in Shenzhen and its peace declaration, the World Court's ruling that Myanmar committed genocide against the Rohingya, Anthropic's record $81 billion IPO, tankers hit by mines in the Strait of Hormuz, Voyager 1 reaching one light-day from Earth, GTA VI's launch after a 13-year wait, and a migrant boat capsizing off Senegal. The news is embedded in the program; it runs offline and deterministically with only Python's standard library and Pillow.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes out/entry.png (without the env var it writes /output/entry.png).
